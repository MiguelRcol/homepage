# Miguel Rua — Homepage

Personal portfolio homepage for Miguel Ángel Rua Ruiz, an engineering student growing into full-stack development.

This repository is intentionally dedicated to the homepage only. Its GitHub Pages workflow publishes only `index.html`, `styles.css`, and the `assets` directory from the `main` branch.

## Local preview

Open `index.html` directly or serve the repository with any static HTTP server.

## Deployment

Pushes to `main` trigger `.github/workflows/pages.yml`. The expected production URL is:

`https://miguelrcol.github.io/homepage/`
